# Codex handoff

## 現在の入口

- 起動: `npm start`
- 入力: `../data/raw/`
- 実装: `src/`、`public/`
- 診断: `scripts/diagnostics/`
- テスト: `npm run check && npm test`

## 動作済み

- 録画フォルダの5秒間隔監視
- 一覧で `待機中 / 確認中 / 分割中 / 分析中 / 分析済み / 失敗` を表示
- ルール表示とHUDから試合区間を検出し、音声付きMP4へ分割
- 分割済み動画の再利用
- HTTP Range対応の動画配信
- 自分のデスを0.25秒刻みの専用HUD領域から検出
- 8人のHUDアイコンから1秒ごとの生存人数と人数差を生成
- 動画、シークバー、デス帯、人数差グラフ、分析ポイントの同期

## 基準録画

`2026-08-08 15-20-32.mp4` は4試合として検出済み。

| 試合 | 元録画区間 | 長さ | 自分のデス |
| --- | --- | --- | --- |
| 01 | 22〜404秒 | 382秒 | 9件 |
| 02 | 440〜736秒 | 296秒 | 10件 |
| 03 | 764〜1044秒 | 280秒 | 9件 |
| 04 | 1072〜1428秒 | 356秒 | 8件 |

解析JSONはバージョン3。人数推移は `gameFlow.playerCounts` に保存する。`source=observed` はHUDを直接読めた秒、`source=held` はマップ表示などでHUDが隠れたため直近値を最大5秒保持した秒。

## 次に実装するもの

1. ゲームカウントOCRと、生存人数・自分のデスとの同一時間軸表示
2. 映像内で視認できた敵味方の検出、枠、ブキ名
3. 自分の試合全体の動線
4. 視認情報に基づく敵味方の短時間予想動線とステージマップ同期

知覚できなかった敵味方の実位置は表示しない。観測値と予想値は解析JSONでもUIでも区別する。
