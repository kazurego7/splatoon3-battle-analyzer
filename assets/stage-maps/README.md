# ステージ俯瞰画像

アプリがステージとルールに合った俯瞰画像を表示するためのローカル素材置き場です。第三者画像の再配布を避けるため、完成画像はGitHubリポジトリに含めません。

- `images/`: `<ステージ名>_<ルール名>.webp` 形式のローカル画像（Git管理外）
- `map_urls.csv`: 各画像の出典ページ、直リンク、版番号、サイズ、SHA-256
- `missing_rules.csv`: 出典ページに画像がない組み合わせ
- `summary.json`: 最終同期時の件数

取得・更新はリポジトリ同梱の `$sync-splatoon-stage-maps` スキルを使用します。利用者は取得元の利用条件を確認してください。完成画像、取得途中のファイル、監査レポートはすべてGit管理外です。
