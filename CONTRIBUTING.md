# Contributing

Thank you for helping improve the project.

1. Do not commit gameplay recordings, screenshots, downloaded stage images, extracted game assets, generated weapon catalogs, credentials, or personal analysis data.
2. Run `npm ci`, `npm run check`, `npm test`, and `npm run check:public` from `app/` before opening a pull request.
3. Keep generated output under `data/`, downloaded tools under `tools/runtime/`, and third-party local assets in their documented ignored locations.
4. Explain user-visible behavior changes and add tests for analysis logic where practical.

By contributing original code, you agree that it may be distributed under the repository's MIT License. Do not contribute material you do not have permission to redistribute.
