# Battle Review Mock Demo

このフォルダは、2026-08-08時点のUI・操作検証用モックデモです。今後のアプリ本体は `../app` で開発します。モックの見た目や挙動を参照する場合を除き、このフォルダへ新機能を実装しません。

動画とステージマップを同期し、プレイヤーがその場で知覚できた情報だけを再構成するローカルWebアプリです。動画・解析JSON・ステージ画像はブラウザ内で読み込み、外部へ送信しません。

## 使い方

1. `index.html` を開く
2. ヘッダーの「試合データを開く」を選択
3. 解析JSONを選択し、必要なら動画とステージマップも選択
4. ステージ名とルールを入力して「読み込んで表示」

`analysis-example.json` を最小構成のテンプレートとして利用できます。「現在のJSONを書き出す」から、画面で使用中の解析データも保存できます。

## できること

- 動画・マップ・HP・敵位置・動線の時刻同期
- 確認できた敵位置と推定位置の区別
- デス前に映像へ入った敵・味方をバウンディングボックスで表示
- 映像で確認できた位置だけをマップへ表示
- 最後に確認した敵・味方の移動ベクトルから短時間予測を表示
- 時間経過に合わせて予測範囲を広げ、確度を薄く表示
- 自分の試合全体の動線を薄く残し、現在時刻の前後だけを強調
- 未確認の敵・味方の実位置は非表示
- 映像の検出枠へ敵・味方のブキ名を表示
- シークバーと同じ左右端・同じ時間軸で、自チーム／相手チームのカウント推移を段階線で表示
- 味方と相手の生存人数から、人数有利・五分・人数不利を連続した帯で表示
- 自分がデスした瞬間を、カウントグラフ上の赤い縦線と菱形で表示
- シークバー直下・グラフ直上に、現在時刻・両チームのカウント・人数差をまとめて表示
- 動画クリックで再生／一時停止し、独立した再生・±5秒・速度操作列を置かない構成
- グラフの現在時刻カーソルを動画と同期し、クリックでシーク
- デスと分析ポイントをシークバーとアドバイス一覧へ表示

敵・味方の検出データは現状UI確認用のサンプルです。

## 起動

`index.html` をブラウザで直接開けます。標準のデモ動画を使用する場合は、大容量動画のシークに必要なHTTP Rangeリクエストへ対応したWebサーバーの利用を推奨します。画面からローカル動画を選ぶ場合は、ファイルのオブジェクトURLを使用します。

## 解析データ

画面の位置・HP・視認情報は `app.js` 冒頭のデータにまとまっています。現状はUI動作確認用のサンプルです。

- `route`: `[動画秒, X座標, Y座標, HP]`
- `enemies[].points`: `[動画秒, X座標, Y座標]`
- `events`: デス／分析ポイントと見るポイント
- `detections`: 映像上の枠と同時刻のマップ確認位置
- `gameFlow.teamCount` / `enemyCount`: `[動画秒, カウント]`
- `gameFlow.deaths.self` / `ally` / `enemy`: `[デス開始秒, 復帰までの秒数]`

座標はマップSVGの `1000 × 1000` を基準にしています。動画解析パイプラインから同じ形のJSONを出力すれば、サンプルデータを差し替えられます。
