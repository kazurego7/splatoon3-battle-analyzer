# Battle Review — Codex 引き継ぎ

## 最初にCodexへ依頼する内容

このファイルと `README.md` を読み、既存のローカルWebアプリを継続実装してください。動画・解析JSON・ステージ画像の読み込み、動画・マップ・グラフの同期、知覚情報だけを表示する仕様を維持してください。実装後は `node --check app.js` とブラウザ上の表示・シーク同期を確認してください。

## プロダクトの目的

スプラトゥーン3の試合映像を、動画・ステージマップ・分析内容を同期させて振り返るための画面。

中心に置くのは、AIが答えを断定することではなく、プレイヤーがその場で知覚できた情報と、そこから予想できた情報を可視化し、本人が状況を理解できること。

## 現在の重要仕様

- 動画、ステージマップ、アドバイスを並列表示する。
- 動画とマップは同じ時刻で同期する。
- 動画上では、視認できた敵・味方を枠で囲み、ブキ名を表示する。
- 動画やマップへ、プレイヤーが知り得なかった敵・味方の実位置を表示しない。
- 視認済みの位置と移動から予想できる敵・味方の動線はマップへ表示する。
- 自分の試合全体の動線は残し、現在時刻付近を濃く、それ以外を薄く表示する。
- アドバイスはデスと分析ポイントを対象にする。
- 動画のシークバーにはデスと分析ポイントを表示する。

## 試合フローグラフの現状

- 動画シークバーとグラフは、左右端と時間軸が一致している。
- 自チームと相手チームのカウント推移を段階線で表示する。
- 生存人数の差を、人数有利・五分・人数不利の連続した帯で表示する。
- シークバー直下・グラフ直上に、現在時刻、両チームのカウント、`自3–敵4・1枚不利` のような人数差を表示する。
- 自分がデスした瞬間を、カウント線と人数差を貫く赤い縦線と菱形で表示する。
- グラフをクリックすると、動画、シークバー、マップ、人数表示が同じ時刻へ移動する。
- グラフのタイトル、再生・±5秒・速度調整の独立操作列は置かない。動画クリックで再生・一時停止する。

## 現在の実装段階

デモから、動画・解析JSON・ステージ画像をローカルで読み込めるアプリへ移行済み。解析JSONの検証、現在データのJSON書き出し、デモへの復帰ができる。次の機能追加は、現在の簡潔なグラフ構成を崩さないこと。

## 主なファイル

- `index.html`: 3カラム画面と試合フローSVG
- `styles.css`: 画面全体、人数差帯、デスタイミングの見た目
- `app.js`: サンプル分析データ、同期処理、マップ描画、試合フロー計算・描画
- `README.md`: 現在できることとデータ形式

## 関連する実装箇所

`app.js`:

- `analysis.gameFlow`: カウント・デスのサンプルデータ
- `FLOW`: SVG内の描画領域
- `playerStateAt(time)`: 生存人数と人数差
- `advantageSegments()`: 人数差の区間生成
- `buildFlowChart()`: グラフの静的描画
- `updateFlowChart(time)`: 現在時刻カーソルと状態表示
- `flowHitArea` の `pointerdown`: グラフクリックによるシーク

`styles.css`:

- `.flow-advantage-band.*`: 人数差の帯
- `.flow-self-death-line`, `.flow-self-death-marker`: 自分のデスタイミング

## サンプルデータ形式

```js
gameFlow: {
  teamCount: [[動画秒, カウント], ...],
  enemyCount: [[動画秒, カウント], ...],
  deaths: {
    self: [[デス開始秒, 復帰までの秒数], ...],
    ally: [[デス開始秒, 復帰までの秒数], ...],
    enemy: [[デス開始秒, 復帰までの秒数], ...]
  }
}
```

現状はすべてUI確認用のサンプルデータ。実際の動画解析結果ではない。

- グラフクリックで動画時刻とシークバーが同時に更新された。
- ブラウザのコンソールに警告・エラーはなかった。

## 完了条件

- 狭い画面でも時刻・カウント・人数差が読める。
