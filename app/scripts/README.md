# Scripts

アプリ本体から直接呼ばれない、開発・検証用のコマンドを置きます。

- `diagnostics/`: 現在の解析機能を個別に確認する安定した診断コマンド
- `experiments/`: 未完成機能の調査コード。製品パイプラインへ組み込まれるまではここに置く

通常の起動では、これらを実行する必要はありません。利用できるコマンドは `package.json` の `scripts` を参照してください。

編成取得の候補フレームは `npm run audit:weapon-roster-candidates` で全録画を監査できます。録画IDまたはファイル名を引数に渡すと対象を限定できます。
