# Codex handoff

## 現在の入口

- 起動: `npm start`。Tailscale経由の起動: `npm run start:tailscale`
- 入力: OBSで設定した録画先。手動追加は `../data/raw/`
- 実装: `src/`、`public/`
- 実装済み解析の診断: `scripts/diagnostics/`
- 実験・校正: `scripts/experiments/`
- 検証: `npm run check`、`npm test`、`npm run check:public`

## 変更時に維持すること

- 試合は元録画と開始・終了時刻で管理する。解析・シーク・レポートでは試合開始を0秒とする。
- 録画中は個人リザルトの安定検出後に試合を公開する。ローカルは録画中から元録画を直接再生し、圧縮断片はリモート用とする。断片は録画終了後に片づけ、リモートはR2を使用する。
- ローカル再生用の試合MP4を重複生成しない。R2への転送時に再生用の軽量動画を生成する。
- 勝敗、デス、K/D、カウントなどのローカル解析は、任意のAIデス分析と独立して利用できるようにする。
- AI分析では保存済みの事前分析と、AI自身が試合全体から選んだ時刻の画像を使う。デス一覧の完成を先に表示し、続けて俯瞰レポートを生成する。
- AI分析は明示実行または自動実行の設定時だけ使う。手動実行の失敗は原因を表示し、現在の保存形式の途中成果から再開できるようにする。
- 録画中の未取得メタデータは録画終了後に補完する。未取得値を推測やサンプル値で埋めない。
- 元録画、解析結果、転送済みオブジェクトを互換処理の整理に伴って削除しない。

## 解析の回帰検証

人が確認したラベルは `test/fixtures/` と `config/` の検証用データを参照する。録画ごとの過去の検出件数を現在の正解として文書へ転記せず、必要なローカル録画を指定して検証コマンドを実行する。教師データは自動出力の検証に使い、解析結果を手動補正するためには使わない。
