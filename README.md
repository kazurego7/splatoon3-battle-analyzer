# splatoon3-battle-analyzer

スプラトゥーン3のバトル分析アプリです。

キャプチャーボードで録画した長時間動画を、録画中から試合ごとに自動分析し、個人リザルトが出た直後にブラウザで振り返るためのローカルアプリです。録画や解析結果はPC内に保存されます。R2を設定すると、再生用の試合動画をクラウドへ自動転送します。

## できること

- 録画中に試合区間を見つけ、ローカルでは録画中の元ファイルを元画質で直接再生
- 個人リザルト表示後に振り返りを開始。リモートでは圧縮した短い動画断片、転送済みならR2の軽量試合動画を使用
- 再分析や録画終了後の詳細補完で、ルール名・ステージ名・自分のブキを判定
- 勝敗発表、デス、敵味方の生存人数、ゲームカウント、ペナルティを自動判定
- 各デスの行動シーケンスをAIで整理し、同じ試合で繰り返す失敗パターンを抽出（任意）
- 動画、グラフ、マップ画面を同じ時刻に連動
- ステージ俯瞰画像を使って試合中の位置情報を振り返り

## 必要なもの

- Windows 10 / 11
- Node.js 22以上
- MP4などのゲーム録画
- FFmpeg（環境変数 `FFMPEG_PATH` で `ffmpeg.exe` を指定）

AIによるデス場面の説明は任意機能です。使う場合だけCodexへログインしてください。ローカル解析と通常の画面表示には不要です。

## はじめかた

PowerShellでプロジェクトを開き、次を実行します。

```powershell
cd app
npm install
npm start
```

ブラウザで <http://127.0.0.1:4310> を開きます。OBSでいつもどおり録画を始めると、OBS設定から保存先を自動で見つけ、通常は5〜10秒以内に処理が始まります。手動で `data/raw/` へ録画を置く方法も引き続き使えます。

録画中の試合は「分析中」、個人リザルトを検出した試合はすぐに開ける状態になります。ローカルはOBSの録画停止や圧縮動画の準備を待たず、元録画の該当時刻を直接使います。OBSは録画中も読み出せるハイブリッドMP4を使用します。録画終了時にはリモート用の一時断片を削除し、ローカル用の試合MP4は重複して作りません。リモートは以後R2の軽量試合動画を使います。画像もローカルでは保存された元画像、リモートだけ縮小・圧縮したものを使います。

## データの保存場所

| 内容 | 場所 |
|---|---|
| 入力する元録画 | OBSで設定した録画先（手動追加は `data/raw/`） |
| 試合区間・解析結果 | `data/app/`（動画本体は元録画を参照） |
| 録画中に作る再生用断片 | `data/live-media/` |
| 解析結果・サムネイル | `data/app/` |
| 再生成できる一時データ | `data/work/` |
| ステージ俯瞰画像 | `assets/stage-maps/images/` |

`data/`、ローカル実行環境、確認用の一時画像、ダウンロードしたステージ画像、ローカル生成したブキ辞書はGitへ入りません。元録画や第三者素材を誤って公開しないため、プロジェクト直下の `.gitignore` で一括して除外しています。

## 任意: AIによるデス分析

```powershell
cd app
npx codex login
npm start
```

試合の分析画面で「AI分析」を押すと、Codexが事前分析データを読み、試合全体から必要な時刻・範囲の画像を抽出して調査し、2件以上で繰り返す失敗パターンを抽出します。試合画面ではレポートダイジェストの下にデスを縦一覧で表示し、各項目を選ぶと映像の8秒前へ移動します。「俯瞰レポート」からは長い分析を別ウィンドウで開けます。レポートではパターンごとに独立した動画を置き、根拠場面を順にループするクリップモードと、試合全体を自由に見る通常再生を動画ごとに切り替えられます。動画ファイル自体は切り抜かず、元の試合動画上に複数の範囲として表示します。

AIを使わない限り映像由来画像は外部へ送信されません。APIキーへの自動切り替えは行いません。

録画の初回解析時にも自動実行したい場合だけ、起動前に `$env:CODEX_DEATH_ANALYSIS = "true"` を設定してください。画面のボタンはこの環境変数がなくても利用できます。

## ステージ画像を更新する

リポジトリには `$sync-splatoon-stage-maps` スキルを同梱しています。Codexへ「ステージ画像を最新版へ更新して」と依頼すると、画像の取得、版番号の比較、WebP検証、欠損・重複チェック、出典一覧の更新をまとめて実行します。画像は第三者素材のためGit管理外で、利用者自身が取得元の利用条件を確認したうえでローカル利用します。

画像を取得済みの場合は、スキル内のスクリプトで手元の素材だけを検査できます。

```powershell
python .agents/skills/sync-splatoon-stage-maps/scripts/sync_stage_maps.py check
```

## よくある問題

- **画面が開かない**: Node.jsが22以上か確認し、`app/` で `npm install` を実行してください。
- **動画処理でFFmpegエラーになる**: `FFMPEG_PATH` に利用可能な `ffmpeg.exe` のフルパスを設定してください。
- **OBS録画を始めても分析されない**: OBSの録画設定に保存先が入っていることと、アプリを起動したままにしていることを確認してください。手動追加では `data/raw/` 直下へ動画を置きます。
- **解析結果を作り直したい**: 画面の再分析ボタンを使うか、`app/` で `npm run analyze -- "録画ファイル名"` を実行してください。
