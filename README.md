# Battle Review App

スプラトゥーン3のプレイ映像を、ステージマップ・知覚情報・試合状況・分析ポイントと同期して振り返るためのアプリ本体です。

## 現在の状態

新規開発用の独立Gitリポジトリを作成した段階です。技術構成を決めてから、モックの必要な機能を移植します。

## モックデモ

UIと同期操作の参照実装は `../battle-review-mock-demo` に保存しています。

- 動画・マップ・アドバイスの3カラム表示
- 動画とマップの時刻同期
- 視認できた敵・味方の映像オーバーレイとブキ名
- 自分の全動線と、視認情報から予想した敵・味方の動線
- シークバー上のデス／分析ポイント
- カウント推移、人数有利・不利、自分のデスタイミング
- ローカル動画・解析JSON・ステージ画像の読み込み

モックは参照用として扱い、新規実装はこのリポジトリ内で行います。

## プロダクト方針

- プレイヤーがその時点で知覚できた情報と、そこから合理的に予想できる情報だけを表示する
- AIが正解を断定するのではなく、事実・パターン・示唆から本人の気づきを支援する
- 動画、シークバー、グラフ、マップ、分析ポイントを同一の時間軸で扱う
- 実データと推定データを視覚的に区別する
